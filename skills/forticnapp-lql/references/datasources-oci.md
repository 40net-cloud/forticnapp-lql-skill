# Datasource Metadata

## OCI Configuration Datasources

All Oracle Cloud Infrastructure (OCI) configuration datasources in this section have the same metadata, as listed in the following table.

### All

- `LW_CFG_OCI_ALL` — Results from all OCI configuration data

### Block Volume

- `LW_CFG_OCI_BV_VOLUME` — OCI Block Volume resource
- `LW_CFG_OCI_BV_VOLUMES` — OCI Block Volume resource

### Certificates Management

- `LW_CFG_OCI_CERTIFICATEMANAGEMENT_CERTIFICATES` — OCI Certificates resource

### Compute

- `LW_CFG_OCI_COMPUTE_INSTANCES` — OCI Compute Instance resource

- `LW_CFG_OCI_FS_FILE_SYSTEM` — OCI file system resource
